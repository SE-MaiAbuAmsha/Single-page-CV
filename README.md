# Single-page-CV
## 📋 Project Description
This is a simple, single-page CV built using only HTML. The project focuses on creating a structured and semantic layout for a Curriculum Vitae, including sections for education, skills, and work experience. Styling will be added in a future project.

## 🎯 Project Goals
- Practice writing semantic HTML
- Create a well-structured CV layout
- Implement SEO meta tags for better search engine visibility
- Add Open Graph tags for social media sharing
- Include a favicon for the page

## ✨ Features
- Semantic HTML structure
- SEO-optimized meta tags
- Open Graph tags for social sharing
- Custom favicon
- Clean and organized sections:
  - Personal Information
  - Skills
  - Education
  - Work Experience
  - Contact Links

## 🛠️ Technologies Used
- HTML5
